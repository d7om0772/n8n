# فيديو كولاج موشن جرافيك: كلوفا × محاصيل القهوة (تيك توك)

| الملف | الوصف |
|---|---|
| `klova_coffee_tiktok.mp4` | الفيديو النهائي بمقاس 1080×1920 (9:16) و30 إطار/ث، مدته 22.69 ث، وهي نفس مدة التعليق الصوتي |
| `cover.jpg` | صورة غلاف مقترحة (لقطة الهوك) |
| `voiceover.wav` | التعليق الصوتي (لهجة سعودية) |
| `klova_coffee.srt` | ترجمة على مستوى الجملة |
| `klova_coffee_words.srt` | ترجمة كلمة بكلمة (تزامن النص مع الصوت) |
| `source/` | المشروع كامل لإعادة التصدير أو التعديل |

## الهوية
- الخلفية: `#BD9484` (لون براند كلوفا من المتجر) ثابتة طول الفيديو.
- ألوان النص: إسبريسو `#2A1711` وكريمي `#FFF3E4`.
- الخطوط: Lalezar للعناوين وCairo للبيانات.
- الشعار صغير أعلى المنتصف طول الفيديو، وفي النهاية يكبر وينتقل لشاشة الختام.

## التسلسل
1. الهوك: إذا تسوي قهوتك في البيت؟ / هذا الفيديو لك
2. التعريف: حنّا كلوفا، متجر متخصص في محاصيل القهوة
3. التمييز: الفرق مو في المكينة ❌، الفرق في المحصول ✔️
4. المحاصيل والنكهات: طوابع دول المنشأ، ثم نكهات (توتي، شوكولاتة، حمضي)
5. الختام العاطفي: بدون ما تدفع كل يوم في الكوفيات / بدون ما تتنازل عن الطعم ❤️
6. شاشة النهاية: الشعار + رابط المتجر + الحسابات + أرقام التواصل

## إعادة التصدير
```bash
cd source
python3 build.py      # يبني index.html وsfx_events.json من timing.json
python3 mix.py        # يدمج التعليق مع المؤثرات ويضبط الصوت على -14 LUFS
python3 render.py video video_noaudio.mp4
ffmpeg -i video_noaudio.mp4 -i mix.wav -c:v copy -c:a aac -b:a 192k -shortest out.mp4
```
المتطلبات: Python 3 مع pillow وnumpy وscipy وplaywright، إضافة إلى Chromium وffmpeg.
