# كلوفا — فيديو موشن جرافيك بأسلوب الكولاج (تيك توك 9:16)

- `klova_collage_tiktok.mp4` — الفيديو النهائي 1080×1920، 30fps، مدته 20.8 ثانية (نفس مدة المقطع الصوتي)
- `cover.png` — صورة غلاف مقترحة من الفيديو

## الأسلوب
- كولاج ورقي: قصاصات بحواف ممزقة، ستيكرات بحدود ورقية، شريط لاصق، طباعة هافتون (ريزو)، رسومات يدوية، وحركة "stop-motion" خفيفة
- لوحة ألوان موحّدة في كل اللقطات: كريمي `#F1E6D2` · كرافت `#C99B6D` · إسبريسو `#24150E` · بني محمّص `#6E3B22` · برتقالي `#FF5B2E` · أصفر `#FFC93C`
- الخطوط: Lalezar (العناوين) و Marhey (الملصقات) — Google Fonts (OFL)
- النص يظهر كلمة بكلمة متزامن مع ملف الـ SRT
- بدون موسيقى خلفية — فقط مؤثرات صوتية مولّدة برمجياً (whoosh، ختم، تمزيق ورق، pop، قلم، كاشير، …) تحت مستوى صوت التعليق

## إعادة البناء (src/)
1. `python3 gen_svg.py && node raster.js svg assets` — رسم العناصر
2. `python3 render.py full video_noaudio.mp4` — رسم الفيديو (ويولّد `sfx_events.json`)
3. `python3 sfx.py voice.wav sfx_events.json mix.wav` — توليد المؤثرات ومكساجها مع الصوت
4. دمج الصوت والصورة بـ ffmpeg مع تسوية الصوت إلى ‎-14 LUFS
