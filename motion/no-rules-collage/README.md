# لا توجد أي قواعد — كولاج موشن جرافيك (15 ثانية)

فيديو عمودي 1080×1920 بسرعة 24fps، والصوت ستيريو AAC. كل الصور والحركة والموسيقى والمؤثرات مولّدة بالكود، بدون أي صور خارجية.

| الوقت | المشهد | الحدث |
|---|---|---|
| 0.0–3.0 | لا توجد أي قواعد | الكلمات تنصفع على ورق كرافت مع كل ضربة إيقاع، ثم دائرة ماركر وختم «NO RULES» |
| 3.0–5.0 | قُص | مقص يقص خط الكوبون، والكولاج ينقسم نصفين ويكشف كلمة «قُص» |
| 5.0–7.0 | الصق | صفحة جريدة تنلصق، شريط لاصق، شمس هاف‌تون، وصورة بولارويد |
| 7.0–9.0 | اكسر | ورقة «القواعد:» تتشقق ثم تتفجر شظايا |
| 9.0–11.0 | اخلط | الخلفية تتبدل مع كل ضربة، والخط يتغير كل 3 لقطات، وعناصر تدور ثم تنسحب للمركز |
| 11.0–13.0 | القاعدة الوحيدة؟ | هدوء وتكات ساعة وتصاعد (riser) |
| 13.0–15.0 | ابدأ. | انفجار كل القصاصات، وختم ختامي |

## إعادة التصيير
```bash
npm i                      # خطوط @fontsource
pip install numpy scipy imageio-ffmpeg
python3 audio.py           # → audio.wav
node render.js frames      # → frames/f0000.jpg … f0359.jpg (Playwright + Chromium)
ffmpeg -framerate 24 -i frames/f%04d.jpg -i audio.wav -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest out.mp4
```
