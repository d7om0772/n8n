# التجميعة الجاهزة vs التجميع قطعة قطعة — RTX 5060

فيديو تيك توك عمودي (1080×1920، ‏30fps، ‏34 ثانية) لحساب متخصص بالبي سي: موشن جرافيك عربي مدمج مع لقطات حقيقية، وتعليق صوتي بصوت **Charon** بلهجة سعودية، ومؤثرات صوتية فقط (بدون موسيقى).

| الملف | الوصف |
|---|---|
| `prebuilt_vs_custom_rtx5060.mp4` | الفيديو النهائي (H.264 + AAC، الصوت مضبوط على ‎-14 LUFS) |
| `cover.jpg` | كفر مقترح (لقطة "ما كنت أحب التجميعات الجاهزة") |
| `voiceover_charon.wav` | التعليق الصوتي الخام |
| `source/` | ملفات المشروع لإعادة الرندر أو التعديل |

## التعليق الصوتي
- مولَّد من Gemini API (نفس محرك Google AI Studio) بالموديل `gemini-3.8-flash-tts` والصوت `Charon`، مع توجيه بلهجة سعودية نجدية عامية.
- تم التحقق منه بتفريغ آلي: النص مطابق 100٪، "RTX 5060" تُنطق "آر تي إكس فيفتي سكستي" و"DDR5" تُنطق "دي دي آر فايف".

## القواعد المطبقة
- **لا صور ذوات أرواح**: كل اللقطات قطع كمبيوتر فقط (بدون أشخاص أو وجوه أو أيدي)، وتم فحصها إطار بإطار (إطار كل ثانية). صور المعلّقين في واجهة التعليقات رموز نصية (PC / RX / FPS) وليست وجوه.
- **لا موسيقى**: مؤثرات صوتية فقط (whoosh، نقرات، كيبورد، عدّاد، "كاتشنغ"، تنبيه). تم فحص الصوت النهائي آلياً للتأكد من خلوه من أي موسيقى.

## إعادة الرندر
المتطلبات: `ffmpeg`، ‏Python 3 (numpy، ‏faster-whisper للمحاذاة)، ‏Node + Playwright (Chromium)، والمتغيرات `GEMINI_API_KEY` و`PEXELS_API_KEY`.
```bash
cd source && mkdir -p tts footage/prev frames sfx/wav
python3 scripts/tts.py gemini-3.8-flash-tts tts/voice.wav a      # التعليق الصوتي (Charon)
ffmpeg -i tts/voice.wav -ar 16000 -ac 1 -f f32le tts/voice16.f32
python3 scripts/align.py medium                                  # توقيت الكلمات
python3 scripts/gethd.py 34289018 34280528 5467289 34821018 30518577 10470834 6754834 3147349
bash scripts/clips.sh                                            # إطارات اللقطات
node scripts/render.js frames/out 30 0 34.0 4                    # رندر الموشن (1020 إطار)
python3 scripts/mix.py && bash scripts/final_audio.sh            # المؤثرات + المكساج
ffmpeg -framerate 30 -i frames/out/f_%05d.png -i mix.wav -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest out.mp4
```
ملاحظة: كل التوقيتات في `index.html` مربوطة بتوقيت الكلام (`data/word_timings.json`). لو أعدت توليد الصوت فتأكد من تحديث أوقات الكلمات في `buildHL(...)` داخل `index.html` وجدول المؤثرات في `mix.py`.
